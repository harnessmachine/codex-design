## What The Grid Means

The grid communicates:

- page scale;
- margins;
- columns;
- long-page rhythm;
- implementation-friendly spacing.

The grid does not communicate:

- visual style;
- colors;
- typography;
- content blocks;
- component labels;
- brand identity.

Do not ask ImageGen to render the grid overlay. Attach it as structural context and describe it as an invisible layout guide.
