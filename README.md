# Codex Design

Два скилла для AI-агента, которые ведут страницу от идеи до визуального референса:

```text
design-grill  →  docs/<тема>-design.md + прототип  →  design-art  →  референсы секций  →  код (например, image-to-code)
```

1. **design-grill** — договориться, что на странице и в каком порядке.
2. **design-art** — решить, как это выглядит, и получить картинки секций, по которым можно верстать.

## design-grill

Грил — допрос по вашей идее — не в терминале, а на аккуратной странице в браузере.

Агент задаёт вопросы раундами. У каждого вопроса два-четыре варианта, совет агента и короткое «почему». Вы выбираете варианты, пишете свой ответ или спрашиваете в обсуждении и отправляете всё одной кнопкой. Агент отвечает, уточняет советы и выкладывает следующий раунд, пока не решено всё.

**Что получается в конце**

- **Документ с решениями** — `docs/<тема>-design.md`: словарь терминов, зачем это всё, ключевые решения с таблицей оценок, остальные выборы, риски, отложенное и открытые вопросы.
- **Прототип** — `docs/<тема>-visual.html`, если нажать «Прототип»: HTML-набросок по ответам, нерешённые места помечены.
- **Следующий шаг** — агент предлагает запустить design-art и сделать первый визуальный референс по этому документу.

**Как идёт работа**

1. Пишете агенту: `/design-grill лендинг курса: раскладка блоков`.
2. Открывается страница: вопросы слева, текущий вопрос по центру, обсуждение справа.
3. Выбираете варианты, при желании спрашиваете «а что это?», жмёте «Отправить».
4. Агент отвечает и добавляет следующий раунд. Важные вопросы помечены «Важное решение», вопросы вкуса — «На ваш вкус».
5. «Прототип» рисует набросок, «Завершить» собирает итоговый документ.

Если агент перестал слушать страницу, она скажет об этом. Напишите агенту в чат **грил** — он заберёт сохранённые ответы и продолжит.

Нужен Node.js 20+, других зависимостей нет. Сервер слушает только `127.0.0.1` и ничего не отправляет наружу. Сессии хранятся в `~/.design-grill` (меняется переменной `GRILL_HOME`).

## design-art

Визуальные референсы для лендинга, сайта или экрана — по одной картинке на секцию плюс склейка всей страницы. Кода не пишет: это вход для верстки.

**Как идёт работа**

1. Читает документ из design-grill, если он есть, и спрашивает только о внешнем виде.
2. Предлагает 3–5 визуальных направлений с объяснением, что каждое меняет. Можно дать свой референс.
3. Фиксирует выбранный стиль и генерирует каждую секцию в нём, по сетке.
4. Оценивает каждую картинку на собираемость и читаемость, слабые перегенерирует.
5. Склеивает секции в превью всей страницы и собирает пакет для реализации: картинки, стиль, порядок секций, заметки.

Сделан под Codex: нужны встроенная генерация изображений и субагенты.

## Установка

Codex:

```sh
git clone https://github.com/harnessmachine/codex-design ~/codex-design
ln -s ~/codex-design/design-grill ~/.codex/skills/design-grill
ln -s ~/codex-design/design-art ~/.codex/skills/design-art
```

Claude Code (design-grill):

```sh
git clone https://github.com/harnessmachine/codex-design ~/codex-design
ln -s ~/codex-design/design-grill ~/.claude/skills/design-grill
```

Обновление: `git -C ~/codex-design pull`.
