# Grill UI

Скилл для AI-агента, который проводит грил — допрос по вашей идее — не в терминале, а на аккуратной странице в браузере.

Агент задаёт вопросы раундами. У каждого вопроса два-четыре варианта, совет агента и короткое «почему». Вы выбираете варианты, пишете свой ответ или спрашиваете в обсуждении, а потом отправляете всё одной кнопкой. Агент отвечает, уточняет советы и выкладывает следующий раунд, пока не решено всё.

## Что получается в конце

- **Документ с решениями** — `docs/<тема>-design.md`: словарь терминов, зачем это всё, ключевые решения с таблицей оценок, остальные выборы, риски, отложенное и открытые вопросы. По нему можно строить, не видя самого грила.
- **Прототип** — `docs/<тема>-visual.html`, если нажать «Прототип»: HTML-набросок по ответам. Нерешённые места помечены.
- **Следующий шаг** — после грила агент предлагает запустить [Machine Art](#дальше-machine-art) и сделать первый визуальный референс по этому документу.

## Для чего подходит

Раскладка лендинга и порядок блоков, экран приложения, пользовательский путь, архитектура фичи — всё, где сначала нужно договориться о решениях, а потом рисовать или писать код.

## Как выглядит работа

1. Вы пишете агенту: `/grill-ui лендинг курса: раскладка блоков`.
2. Открывается страница: вопросы слева, текущий вопрос по центру, обсуждение справа.
3. Выбираете варианты, при желании спрашиваете «а что это?» в обсуждении, жмёте «Отправить».
4. Агент отвечает и добавляет следующий раунд. Важные вопросы помечены «Важное решение», вопросы вкуса — «На ваш вкус».
5. «Прототип» рисует набросок, «Завершить» собирает итоговый документ.

Если агент перестал слушать страницу, она скажет об этом. Напишите агенту в чат **грил** — он заберёт сохранённые ответы и продолжит.

## Установка

Нужен Node.js 20 или новее. Других зависимостей нет.

Claude Code:

```sh
git clone https://github.com/harnessmachine/grill-ui ~/.claude/skills/grill-ui
```

Codex:

```sh
git clone https://github.com/harnessmachine/grill-ui ~/.codex/skills/grill-ui
```

Другие агенты, которые читают `SKILL.md`, — склонируйте в их папку скиллов.

## Устройство

| Файл | Что делает |
| --- | --- |
| `SKILL.md` | инструкции агенту: как вести раунды, слушать страницу, писать итог |
| `server.mjs` | локальный сервер страницы и команды агента `new`, `patch`, `serve`, `wait`, `pending` |
| `page.html` | страница грила |
| `markdown.mjs` | безопасная разметка текста на странице |
| `visual-brief.md` | правила для прототипа |

Сервер слушает только `127.0.0.1` и ничего не отправляет наружу. Сессии хранятся в `~/.grill-ui` (путь меняется переменной `GRILL_HOME`).

## Дальше: Machine Art

Грил отвечает на вопрос «что и в каком порядке». Как это выглядит, решает следующий шаг: после завершения агент предлагает передать документ и прототип в скилл Machine Art, чтобы получить первый визуальный референс страницы. Если Machine Art не установлен, агент предложит другой доступный дизайн-скилл или пропустит шаг.
